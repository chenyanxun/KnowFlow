# 税务法规测试题

这些题对应已经入库的税务法规文本。答案只根据对应文件里的条文整理，方便对照问答结果和出处。

库里没有这些内容时，预期回答是「资料里没有找到相关内容。」，并且不显示出处。

## 能在库里找到的问题

1. 谁应当缴纳增值税？
   - 答案：在境内销售货物、服务、无形资产、不动产，以及进口货物的单位和个人（包括个体工商户）。
   - 出处：《中华人民共和国增值税法》第三条。文件 `中华人民共和国增值税法.txt`。

2. 小规模纳税人怎么认定？
   - 答案：年应征增值税销售额未超过五百万元的纳税人。会计核算健全、能够提供准确税务资料的，可以登记后按一般计税方法缴纳。
   - 出处：《中华人民共和国增值税法》第九条。

3. 销售货物的增值税税率一般是多少？
   - 答案：纳税人销售货物、加工修理修配服务、有形动产租赁服务、进口货物，除另有规定外，税率为百分之十三。
   - 出处：《中华人民共和国增值税法》第十条第一项。

4. 增值税简易计税的征收率是多少？
   - 答案：适用简易计税方法的征收率为百分之三。
   - 出处：《中华人民共和国增值税法》第十一条。

5. 增值税以一个月或一个季度为计税期间时，应在什么期限内申报？
   - 答案：自期满之日起十五日内申报纳税。
   - 出处：《中华人民共和国增值税法》关于计税期间的规定。

6. 企业所得税的税率是多少？
   - 答案：企业所得税的税率为 25%。非居民企业取得该法第三条第三款规定的所得，适用税率为 20%。
   - 出处：《中华人民共和国企业所得税法》第四条。

7. 个人独资企业和合伙企业要不要缴纳企业所得税？
   - 答案：个人独资企业、合伙企业不适用《中华人民共和国企业所得税法》。
   - 出处：《中华人民共和国企业所得税法》第一条。

8. 居民个人综合所得的基本减除费用是多少？
   - 答案：以每一纳税年度的收入额减除费用六万元，再减除专项扣除、专项附加扣除和依法确定的其他扣除。
   - 出处：《中华人民共和国个人所得税法》第六条。

9. 工资薪金所得适用什么个人所得税税率？
   - 答案：工资薪金属于综合所得，适用百分之三至百分之四十五的超额累进税率。
   - 出处：《中华人民共和国个人所得税法》第三条。

10. 稿酬所得怎样计算收入额？
    - 答案：先以收入减除百分之二十的费用，余额为收入额；稿酬所得的收入额再减按百分之七十计算。
    - 出处：《中华人民共和国个人所得税法》第六条。

11. 契税的税率是多少，纳税人是谁？
    - 答案：在境内转移土地、房屋权属，承受的单位和个人是契税纳税人。契税税率为百分之三至百分之五。
    - 出处：《中华人民共和国契税法》第一条、第三条。

12. 契税应在什么时候申报缴纳？
    - 答案：纳税人应当在依法办理土地、房屋权属登记手续前申报缴纳契税。
    - 出处：《中华人民共和国契税法》第十条。

13. 证券交易印花税向买方还是卖方征收？
    - 答案：证券交易印花税对出让方征收，不对受让方征收。
    - 出处：《中华人民共和国印花税法》第三条。

14. 车辆购置税的税率是多少，应在几天内申报？
    - 答案：税率为百分之十。纳税义务发生时间为购置应税车辆的当日，纳税人应当自该日起六十日内申报缴纳。
    - 出处：《中华人民共和国车辆购置税法》第四条、第十二条。

15. 环境保护税按什么周期申报，期限是几天？
    - 答案：按月计算、按季申报缴纳。按季申报的，应当自季度终了之日起十五日内申报并缴纳税款。
    - 出处：《中华人民共和国环境保护税法》第十八条、第十九条。

16. 污染物浓度低于标准时，环境保护税怎么减征？
    - 答案：浓度值低于规定排放标准百分之三十的，减按百分之七十五征收；低于百分之五十的，减按百分之五十征收。
    - 出处：《中华人民共和国环境保护税法》第十三条。

17. 未按期缴纳税款，滞纳金怎么计算？
    - 答案：从滞纳税款之日起，按日加收滞纳税款万分之五的滞纳金。
    - 出处：《中华人民共和国税收征收管理法》第三十二条。

18. 个人所得税综合所得汇算清缴应在什么时间办理？
    - 答案：应当在取得综合所得的纳税年度的次年三月一日至六月三十日内办理。
    - 出处：《个人所得税综合所得汇算清缴管理办法》第五条。

19. 纸质发票丢失后应当怎么处理？
    - 答案：使用纸质发票的单位和个人应当妥善保管发票。发生丢失时，应当于发现丢失当日书面报告税务机关。
    - 出处：《国家税务总局关于修改〈中华人民共和国发票管理办法实施细则〉的决定》第三十五条。
